# Data Drift - Campus Security Demo

## Style Prompt

A restrained Data Drift treatment for a real campus security dashboard. Keep the Web recordings legible and dominant. Use deep black framing, cool white text, cyan as the operational accent, and purple only as a secondary atmospheric glow. The result should feel like a credible student competition demo, not a science-fiction trailer.

## Colors

- Canvas: `#070B12`
- Panel: `#0D1420`
- Foreground: `#E8F5F7`
- Muted text: `#A8C0C8`
- Operational accent: `#06B6D4`
- Secondary glow: `#7C3AED`
- Risk status: preserve the source UI red when it already exists

## Typography

- Headlines: `Bahnschrift`, weight 700
- Body and subtitles: `Microsoft YaHei UI`, weight 400
- Technical labels: `Cascadia Mono`, weight 400

## Motion

- Smooth and continuous: `sine.inOut`, `power2.out`, `power3.out`
- Use short entrance animations and long readable holds
- Let risk points and status chips breathe gently
- Use restrained blur crossfades between chapters

## What NOT to Do

- No flashy transitions
- No cartoon illustrations
- No dense flashes or inversion screens
- No decorative particle storm over the Web UI
- No algorithm terminology as the visual protagonist
