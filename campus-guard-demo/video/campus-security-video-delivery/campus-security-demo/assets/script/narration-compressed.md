传统校园监控主要依赖人工盯屏和事后回放。我们构建了一套面向校园场景的视频行为感知与异常事件智能预警平台，让校园安防从被动记录走向主动预警。

首先是值守工作台，这是异常事件进入处置流程的起点。管理人员可以在同一页面查看多路监控画面，并启动、暂停或中止分析任务。系统会叠加人员目标框、人物 ID 和行为标签。绿色表示行为正常，红色表示检测到异常行为。当系统检测到打架、霸凌、摔倒、翻越、吸烟或使用手机等风险行为时，右侧区域会优先展示高风险告警。待处理告警列表、事件时间轴和系统日志帮助值班人员快速发现风险线索。

除了具体监控画面，平台还提供全校态势总览。校园地图集中展示不同区域的监控点位，并区分正常点位、分析中的点位和存在告警的区域。页面汇总今日告警、未处理警报、高风险告警和在线监控占比，帮助管理人员判断重点区域。

识别不是终点。平台还需要支持人工复核和处置留痕。管理人员可以筛选异常事件，查看截图、视频片段、发生地点、识别置信度和 Track ID，结合视频内容进行复核。随后，管理人员可以标记事件、填写备注并保存处理结果。处理记录会保留从创建、查看到确认的完整过程。

平台支持上传视频源，并将视频与校园区域、楼层和监控位置绑定，从而复用学校已有监控资源，降低初期部署成本。系统状态页面集中展示后端服务、事件流、数据库和模型加载情况，说明平台已经完成前端、模型服务和后端调度之间的协同。

从视频接入、智能识别到风险告警、人工复核和历史追溯，平台形成完整闭环。让校园安防从被动查看走向主动预警。
